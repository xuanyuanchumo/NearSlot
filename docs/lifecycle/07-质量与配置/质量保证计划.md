## 4. 评审流程（权威：[review-system §3](../../quality/review-system.md)）

## 5. 五维检查单（通用，权威：[review-system §2](../../quality/review-system.md)）

- [ ] 功能正确：主链路 + 并发/重复/取消/超时边界
- [ ] 安全：鉴权/越权/注入/密钥（ADR-013）
- [ ] 性能：缓存键/TTL/线程池/SQL 索引
- [ ] 可维护：模块边界/命名/中文注释/ADR 同步
- [ ] 可观测：日志级别/指标埋点/trace 白名单（ADR-011）
