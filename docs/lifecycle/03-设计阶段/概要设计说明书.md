## 2. 正文结构

### 2.1 模块划分与职责（表格优先）

| 模块 | 承载 FR | 提供能力 | 依赖的 common 接口 / RabbitMQ 事件 | SSOT |
|---|---|---|---|---|
| nearslot-common | — | 常量/枚举/异常/Result/UserHolder | 零依赖 | [overview §3](../../architecture/overview.md) |
| nearslot-framework | — | 缓存/锁/幂等/限流/布隆/延迟队列/MQ/ID | 不 import 任何 module（填约束） | [ADR-003](../../architecture/decisions.md) |
| nearslot-module-auth | FR-1 | 双 Token / Lua 族 / 防爆破 | （填事件/接口） | [overview §3](../../architecture/overview.md) |
| nearslot-module-shop | FR-2 | 服务商/技师/时段/GEO/Bloom | （填事件/接口） | 同左 |
| nearslot-module-appointment | FR-3 | 抢约 Lua / 候补 / Hold / 等级校验 | （填事件/接口） | [research/08](../../research/08-nearslot-domain-research.md) |
| nearslot-module-order | FR-4 | 路由表 / 对账 / 回滚失败 / 支付回调 | （填事件/接口） | [overview §4.2](../../architecture/overview.md) |
| nearslot-module-agent | FR-5 | 两阶段规划 / 双闸口 / SSE | （填事件/接口） | [ADR-010](../../architecture/decisions.md) |
| nearslot-app | — | 装配启动（唯一可执行 jar） | 唯一依赖全部模块 | [ADR-001](../../architecture/decisions.md) |
> 填写提示：上表「提供能力/依赖」列为待填位；模块事实以 overview §3 为准，不在此重写职责描述。

### 2.2 模块接口边界

| 边界 | 生产者 | 消费者 | 契约载体（只链接） | NearSlot 填写提示 |
|---|---|---|---|---|
| 同步调用 | 调用方 module | 被调用方 | common 中定义的接口（填接口名） | module 间禁止直接依赖实现，依赖倒置到 common 接口 |
| 异步事件 | appointment/shop | order/agent | RabbitMQ exchange/routing key（填常量） | 抢约成功、缓存失效广播、slot.opened 走事件；可靠参数见 [ADR-008](../../architecture/decisions.md) |
| 领域闸门 | appointment | — | Lua 前置校验 | GEO/等级/时间三闸门与 Agent 双闸口分层，Agent 不得绕过，链接 [research/08 §9](../../research/08-nearslot-domain-research.md) |

### 2.3 跨模块协作机制

| 机制 | 适用场景 | SSOT | 不复制原则 |
|---|---|---|---|
| common 接口 | 需要同步返回结果的跨域能力 | [overview §3 依赖铁律](../../architecture/overview.md) | 只登记接口名与归属模块 |
| RabbitMQ 事件 | 削峰落库、失效广播、slot.opened | [ADR-004/008/014](../../architecture/decisions.md) | exchange/routing key 与幂等策略链接，不重述消费链 |
| framework 注解 | 锁/幂等/限流/延迟队列 | [ADR-003](../../architecture/decisions.md) | 业务模块只写注解，零侵入 |
