## 3. 适配原则（不产出结果）

| 原则 | 说明 |
|---|---|
| 组件替换 | 传统中间件条目须改写为 NearSlot 实际组件（MySQL8/Redis7/RabbitMQ/内嵌 Tomcat/容器/云 WAF）后再执行 |
| 环境差异 | 容器内无 SSH/本地账户等传统检查面，相关条目标不适用而非照抄 |
| 结果归属 | 适配后的检查**结果**写入安全测试报告或运维手册，本索引只维护映射与状态 |
| 禁止编造 | 未适配、未实测前不得填写「通过/符合」，状态保持「待适配」 |
| 门禁关联 | 涉安全项最终由 G4 安全审计 / G5 发布评审验收，口径见 [review-system.md](../../quality/review-system.md) |
