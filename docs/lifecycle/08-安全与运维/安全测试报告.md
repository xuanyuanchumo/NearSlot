# 安全测试报告（模板）

## 2. 正文结构

### 2.1 安全结论（结论前置）

| 项 | 结论 | 目标 | 证据 |
|---|---|---|---|
| 越权测试 | 待填 | 0 次高危越权 | 待填 |
| 注入测试 | 待填 | SQL/XSS/命令注入不可利用 | 待填 |
| 密钥检查 | 待填 | 代码/日志/镜像/异常消息中 0 明文密钥 | 待填 |
| 依赖漏洞 | 待填 | 高危漏洞闭环或豁免有记录 | 待填 |

### 2.2 测试项明细（口径 SSOT：security/guidelines.md）

| 类别 | 检查项 | 依据条款 | 测试方法 | 结果 | 证据链接 |
|---|---|---|---|---|---|
| 越权 | 双闸口：PromptHookChain 前置 + GuardedToolCallback 执行闸口 | §3 / ADR-010 | 高危 BLOCK / 敏感 CONFIRM / 常规 ALLOW 策略投票 | 待填 | 待填 |
| 越权 | @RequiredDataPermission 数据归属（owner 校验） | §3 | 跨用户资源访问断言 | 待填 | 待填 |
| 鉴权 | Token 主动失效 100%；401 按 X-Auth-Reason 分支 | §1 | 改密/踢出 bump version 后旧 token 不可用 | 待填 | 待填 |
| 注入 | SQL 全参数化；动态排序白名单 SORTABLE_FIELDS | §4 | 排序字段注入/订单语句拼接测试 | 待填 | 待填 |
| 注入 | 正则集中 RegexPatterns；XSS 白名单过滤 + 输出转义 + CSP | §4 | 手机号/邮箱/富文本载荷测试 | 待填 | 待填 |
| 注入 | 文件上传 UUID 散列 + 路径穿越校验 + 类型/大小白名单 | §4 | `..` 穿越 / 超大文件测试 | 待填 | 待填 |
| 密钥 | 全部密钥 .env；.env.example 模板；禁入代码/日志/异常/镜像层 | §5 | 镜像层扫描 + 日志抽样 + 代码扫描 | 待填 | 待填 |
| 密钥 | 日志脱敏 maskToken（前 10+...+后 10）、手机号掩码 | §5 | 日志抽样检查 | 待填 | 待填 |
| 依赖漏洞 | CI 定期 mvn dependency-check / OWASP 插件；版本锁定禁 LATEST | §6 | 依赖扫描报告 | 待填 | 待填 |
| 传输 | 生产强制 HTTPS；内部 bridge 网络隔离 | §6 | 端口/证书检查 | 待填 | 待填 |
| 限流 | 登录 IP 60s 5 次 + 账号 24h 10 次；Agent 会话 30 次/60s | §2 | 爆破/频控断言 | 待填 | 待填 |
